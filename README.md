A one-line excuse from a robot vacuum for missing a spot, written for the
[make.fun bounty](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214):
a deadpan little machine that bumped a crumb twice, found it unmoved, and
followed protocol by reclassifying it as furniture — and it does not clean
furniture.

## The entry

> I bumped that crumb twice and it didn't move, so I have officially
> reclassified it as furniture and I don't clean furniture.

124 characters, inside the 1–140 gate. The joke lives in the vacuum's own
world — its bumper sensor, its map, its protocol — and lands on the first
read with a clean turn at the end. A tired homeowner has heard every
appliance excuse; this one is the vacuum keeping a straight face while
doing paperwork on a crumb.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes the line to `/output/entry.txt` (stdlib only, no
dependencies). It asserts the 1–140 character gate before writing.
